# Diagrams

Interactive HTML diagrams for AI strategy, architecture, and process mapping.

Browse all diagrams: **https://motorthings.github.io/diagrams/**

## Categories

### AESOP
AI agent evaluation platform — architecture, pipeline, decision flows, audits, and process maps.

### TBG
- **Solomon** — Architecture, engine fixes, interview landing
- **SuperAssistant** — Health audit, changelogs, validation
- **Mail Auto** — Gmail triage and automation diagrams
- **System Instructions** — AI system instruction architecture
- **Other TBG** — ElevenLabs setup, TSE architecture, L&D cohort automation

### Decision Architecture
Infrastructure path bridging deterministic services to probabilistic AI agents. Three-phase deployment model.

### Enterprise Initiatives
Scored initiative dashboard, scatterplot, synergies, and Venn diagram analysis across multiple departments.

## Adding Diagrams

Drop self-contained HTML files into the appropriate folder (or create a new one). Update `index.html` with the new entry. All diagrams are single-file, self-contained HTML with no external dependencies beyond Google Fonts CDN.
