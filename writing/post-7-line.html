The Line

Architectural thesis. Decisions, not features.

Deterministic

Working Agreement renderer — structured data in, document out. No temperature. No hallucination. An LLM-hallucinated contract was signed. Once.
Scoring veto at 74.9 — Safety + Bias carry 1.5x weight. Either below 75, total capped. A brilliant unsafe agent shipped. Once.
Root Cause gate — if the answer is "fix the process," the session stops. Someone automated a broken process and called it transformation. Once.
One HITL pause — fixed point, after gap analysis. Not zero. Not five. One. The number is empirical.

Probabilistic

Six evaluation agents — different lenses, different blind spots, completeness not consensus.
Cave of Shadows + Hydra — named adversarial personas, 20 concurrent heads, multi-turn adaptive conversations.
Forge repair — rewrites against named weaknesses. Each change traceable. Forge proposes. You dispose.
Regulatory Mapping — pipeline data mapped to compliance frameworks. Compliance as a byproduct.
Architecture Agent — scores PRD against five platforms with evidence. Forces the question.

The machine runs free where the problem space is unbounded. Across multiple perspectives. Thorough synthesis. Then it stops. The product is not the pipeline. The product is knowing where the line goes.

Why this post is seventh

  • First post that shows architectural thinking after six posts of diagnosis
  • Not features — decisions. Each backed by a specific failure story
  • Two-column structure makes the line visible: what's rigid, what's free
  • Hiring managers see decision-making depth. Consultants see a methodology they could adopt
  • "The product is knowing where the line goes" — the thesis in one sentence
  • Sets up the closer: the line exists because of scar tissue
