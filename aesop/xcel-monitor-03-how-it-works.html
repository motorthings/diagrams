HOW IT WORKS

One loop.

Five fixed checks.

A named owner.

Capture the interaction and the retrieval trace: what the agent pulled and the metadata on each chunk. 
Run five deterministic checks: scope, freshness, authority, contradiction, fabrication. 
Roll results up into a rate per failure mode. 
Compare against the last sweep. 
Anything that moves becomes a finding, and a finding always lands with a person. 
(No LLM judge in the loop for these five. It is comparisons on metadata.)
