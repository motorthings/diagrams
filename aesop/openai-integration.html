Run evaluations on OpenAI

NERVE connects to any OpenAI-compatible chat/completions endpoint, so the same eight dimensions can judge models from OpenAI and compatible providers.

01

How it connects

The OpenAI connector is protocol-compatible rather than vendor-locked: it posts chat/completions messages to a configured endpoint, with an optional system message prepended to every evaluation turn.

Protocol
openai
Endpoint
/v1/chat/completions
Model
default gpt-4
System
optional system_message
