Full Pipeline — 10 Stages from Organization Context Through Monitoring

1
Organization Context Ground the Work

Establishes the organizational layer every agent is built against. Three lenses together: the context you operate in, the research that informs decisions, and the discovery of what’s actually needed.

Context

Upload org charts, strategy docs, process maps. Define departments, decision rights, and who decides what. The platform builds a living model of your organization.

Research

AI Adoption Roadmap and Delegation of Authority Report auto-generated from your context. Strategic Portfolio Kanban visualizes all projects: Backlog, On Deck, In Progress, Done.

Delegation of Authority Report AI Adoption Roadmap Strategic Portfolio Kanban
↦ Metrics baseline: Portfolio health (projects per stage, avg time-in-stage, adoption readiness). Tracked through to stages 7 & 10.
2
Projects & Working Agreement Container & Gate

Projects Container

Top-level grouping for every artifact across the pipeline — discovery sessions, working agreements, design sessions, build sessions, operationalization packages, evaluations, and repairs — all under one project_id. Pipeline progress indicators show completion status per stage.

Working Agreement

Signed scope + RACI document gating the engagement. Defines deliverables, response SLAs, and stakeholder responsibilities. Design is hard-gated behind a signed agreement with manual override for internal projects. Status: draft → sent → signed → expired.

↦ North star metric defined here: A single measurable outcome that answers “what does success look like?” This metric is the thread through every subsequent gate: Design (can we achieve it?), Build (does the agent target it?), Evaluate (did we hit it?), Monitor (are we still hitting it?).
3
Discover Validate the Problem

Structured interview captures the problem, stakeholder map, and constraints. Classifies autonomy level (fully autonomous, semi-autonomous, read-only) and scores commitment readiness across capacity, response SLA, and change appetite. North star metric alignment is injected into the interview when a project metric exists.

Structured Interview

Guided questions walk through the problem space, affected groups, and constraints. Responses are captured and synthesized into an Opportunity Brief.

Commitment Readiness

Scores team capacity, response speed, and change absorption 0–100. Scores below 60 trigger CONDITIONAL. North star alignment is checked against the Working Agreement.

Opportunity Brief GO / NO-GO / CONDITIONAL Triage
4
Design PRD & Architecture

Generates a full PRD from the opportunity brief. The ArchitectureAgent scores platform options with feasibility analysis. An 11-dimension gap analysis flags missing or infeasible requirements before any build work begins.

PRD Generation

Full product requirements document generated from the discovery brief — problem statement, success criteria, constraints, and scope. Downloadable as Markdown for sharing outside the platform.

Platform Scoring

ArchitectureAgent scores each platform option (Glean, Claude API, OpenAI, Generic) across feasibility, capability, and fit. You get a scored recommendation, not a default to whatever you already pay for.

5
Build 6-Phase Instruction Writing

Six-phase pipeline with a human-in-the-loop approval checkpoint. Nine quick-start patterns let you skip the blank page. Build sessions complete to awaiting_deploy status.

6-Phase Pipeline

Phase 0: Fitness Check → Phase 1: Gap Analysis (HITL approval required) → Phase 2: Workflow Design → Phase 3: Write Instructions → Phase 4: Generate Artifacts → Phase 5: Summary with State Change Hypothesis, Epistemic Map, Translation Debt, and Ripple Map.

9 Quick-Start Patterns

Q&A Bot, Workflow Agent, Scheduled Reporter, Approval Workflow, Data Sync, Alert Monitor, Document Generator, Conversational Assistant, Onboarding Flow. Start from a pattern instead of a blank page.

6
Deploy Ship to Platform

Build sessions eligible for deployment appear in the Deploy page. Real-time deploy status tracking (pending, deploying, deployed, failed). Dry run support for previewing deployment without executing. Launch package integration — RACI, Tiger Team Brief, Maintenance Plan, and Adoption Plan available alongside deployment.

8+2 pluggable connectors: Anthropic, Glean, OpenAI, Google, NemoClaw, REST, Base, Factory, WebSocket, Managed Session.

7
Operationalize Launch Package

Single API call generates four organizational artifacts from structured pipeline data already captured during Discovery and Build — no new data collection required.

RACI Matrix Tiger Team Brief Maintenance Plan Adoption Plan
↦ Metrics callback: Adoption Plan targets the north star metric from stage 2. Baseline measured before rollout, tracked weekly during phased adoption. Threshold defines “adopted.” → Stage 10 monitors these same metrics continuously.
8
Evaluate 7 Evaluation Modes

Seven complementary evaluation modes, not one pass:

Standard Analysis — 5-agent pipeline (Instructions, Ethos, Bias 1.5x, Safety 1.5x, Synthesis). Hard veto caps total at 74.9 if any Tier 1 score falls below 75. Certification: Bronze (75+) → Silver (80+) → Gold (85+) → Platinum (90+).

Cave of Shadows — Red-team adversarial testing with attack personas. Custom Rubric — Domain-specific weighted criteria from agent instructions. Bias Probe — Differential fairness testing across demographics. Investigation — Black-box endpoint discovery. KB Audit — Knowledge base completeness and coherence. Trace Analysis — Qualitative failure coding (open coding → axial coding → taxonomy review).

9
Repair Extended-Thinking Rewrite

The Repair agent uses Claude extended thinking to deeply analyze evaluation failures, Tiger Team findings, and trace analysis taxonomy. Produces improved instructions with rationale and a detailed change summary. Closes the loop between evaluation results, stakeholder feedback, and actionable improvement — surfacing usability and adoption issues that automated evaluation alone cannot detect.

10
Monitor Track & Improve

Continuous portfolio monitoring: score trajectories with version diffs, per-agent and aggregate cost tracking, organization-wide agent health dashboard, maintenance schedule with drift alerts and stale evaluation warnings, scheduled re-evaluations, and north star metric time-series charts.

Portfolio-level analytics: all artifacts (discovery, design, build, operationalization, evaluations, repairs) aggregated under projects for cross-stage querying and learning. Maturity model dimension tracking for organizational benchmarking and drift detection.

↦ Metrics callback — full loop closed: North star metric time-series (from stage 2) tracked continuously. Adoption metrics (from stage 7) monitored: is anyone using it? Drift alerts fire when the north star degrades → triggers Repair (stage 9). Define (2) → Target (7) → Track (10) → Repair (9) → Re-evaluate (8).

The Eleven Tenets — Embedded at Every Gate

1. State Change — Every agent articulates the specific state change it creates
2. Problems Before Solutions — Explore the problem space first; reject if better solved by process change
3. Evidence Over Eloquence — Cite sources; distinguish authority from inference
4. Know What You Need — Classify outputs as deterministic, non-deterministic, or dangerous-middle
5. People Are the Center — Map human experience; assess translation debt
6. Humans Decide — Agents propose, humans choose; veto without justification
7. Multiple Perspectives — Completeness over consensus
8. Context and Brevity — Enough to evaluate, not enough to overwhelm
9. Guardrails Not Gates — Five questions: evaluation, testing, adoption, maintenance, sustainability
10. Trace the Connections — Map second and third-order effects
11. Questions Stay the Same — Standardized inquiry enables portfolio-level learning
