AESOP Transformation OS

Full Pipeline — From Organization Context Through Monitoring

1
Organization Context Ground the Work
Departments, strategic priorities, dysfunctionality profile, uploaded documents. Establishes the organizational layer every agent is built against.
Delegation of Authority Report AI Adoption Roadmap Strategic Portfolio Kanban
2
Working Agreement Gate the Engagement
Signed scope + RACI document. Defines deliverables, response SLAs, and stakeholder responsibilities. Design is hard-gated behind a signed agreement with manual override for internal projects.
3
Discover Validate the Problem
Structured interview captures the problem, stakeholder map, and constraints. Classifies autonomy level and scores commitment readiness (capacity, SLA, change appetite).
Opportunity Brief GO / NO-GO Triage
4
Design PRD & Architecture
Generates a full PRD, then scores architecture options across platforms (Glean, Claude API, OpenAI, Generic) with feasibility analysis. 11-dimension gap analysis flags missing or infeasible requirements before build.
5
Build 6-Phase Instruction Writing
Fitness Check → Gap Analysis (HITL checkpoint) → Workflow Design → Write Instructions → Generate Artifacts → Summary. 9 quick-start patterns. State Change Hypothesis, Translation Debt, Ripple Map.
6
Deploy Ship to Platform
Certified agents ship to target platforms through 8+2 pluggable connectors. Build session selector, real-time deploy status, dry run support, launch package integration.
7
Operationalize Launch Package
Single API call generates four organizational artifacts from existing pipeline data — no new data collection required.
RACI Matrix Tiger Team Brief Maintenance Plan Adoption Plan
8
Evaluate 7 Evaluation Modes
Standard Analysis (5-agent pipeline, Tier-1 1.5x weight, hard safety/bias veto caps total at 74.9), Cave of Shadows, Custom Rubric, Bias Probe, Investigation, KB Audit, Trace Analysis. Certification: Bronze → Silver → Gold → Platinum.
9
Repair Extended-Thinking Rewrite
Analyzes evaluation failures + Tiger Team findings + trace taxonomy using Claude extended thinking. Produces improved instructions with rationale and tracked change summary. Closes the loop between evaluation, feedback, and improvement.
10
Track Monitor & Improve
Score trajectories, version diffs, per-agent and aggregate cost tracking, portfolio health dashboard, drift alerts, stale evaluation warnings, maintenance schedule, north star metric trends.

The Eleven Tenets — Embedded at Every Gate

1. State Change — articulate the specific state change every agent creates
2. Problems Before Solutions — explore the problem space first
3. Evidence Over Eloquence — cite sources, distinguish authority from inference
4. Know What You Need — classify outputs as deterministic, non-deterministic, or dangerous-middle
5. People Are the Center — map human experience, assess translation debt
6. Humans Decide — agents propose, humans choose; veto without justification
7. Multiple Perspectives — completeness over consensus
8. Context and Brevity — enough to evaluate, not enough to overwhelm
9. Guardrails Not Gates — five questions: evaluation, testing, adoption, maintenance, sustainability
10. Trace the Connections — map second and third-order effects
11. The Questions Stay the Same — standardized inquiry enables portfolio-level learning
