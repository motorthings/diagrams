8
Evaluate

Seven independent evaluation methods test every agent before it goes live. Safety and bias checks are enforced by the platform — if an agent fails either, it cannot ship. No exceptions.

Automated Testing

Every agent is scored on instructions, safety, bias, and alignment with company values.

Adversarial Testing

Probes for manipulation and boundary violations — if the agent can be tricked, you know before production.

Custom rubrics, bias probes, knowledge base audits, and failure analysis provide layered coverage. Every finding links back to source evidence — audit-ready.

9
Repair

When an agent’s scores drop or drift is detected, the Repair workflow analyzes what went wrong and proposes rewritten instructions. The project owner is notified with a repair brief. They review and approve before changes take effect. Every change ships with a changelog and rationale.

10
Monitor

Every agent’s health, cost, and performance visible in one dashboard. Drift triggers an alert to investigate, triage, and iterate. Every agent has a named responsible management sponsor and product owner from the Working Agreement.

Measured: North star and adoption metrics tracked continuously. Drift alerts → investigate → triage → iterate.
11
Transcript Review

Meeting transcripts are ingested and analyzed by an LLM extraction pipeline that identifies proposed portfolio changes — status updates, milestone shifts, new risks, budget changes, timeline adjustments, scope changes, decisions, and action items. Every extracted change routes through a human reviewer before anything is applied to the portfolio.

Measured: Extraction confidence scores, review throughput, applied-vs-rejected ratio. Source-quoted traceability on every change.
