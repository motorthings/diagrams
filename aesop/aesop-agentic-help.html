Recursive self-help system

Every product has help pages. They are a copy of the product, kept somewhere else. Copies drift as the product matures.

So we stopped keeping a copy. The AESOP Transformation OS help reads itself.

01

The product is the documentation.

Typical help systems are static, and get more useless as the app iterates.

The app is the one description of itself that is always current.

So nothing is written by hand. An agent reads the running app and rebuilds the help from it, so the help is only ever as old as the last change.
