02

Three layout modes

The skill picks the mode by content type, not personal preference. Each has a distinct template, container width, and hero treatment.

Mode — MermaidFlowcharts &
architecture
Mermaid Diagram. Use when: branching, diamonds, decisions, complex graphs with many edges, topology-focused architecture. Template template-diagram.html, 1000px container, h1 44px/800 + badge. JS: Mermaid init + zoom/pan + theme toggle.
Mode — OverviewExecutive pages
& showcases
Portfolio / Overview. Use when: numbered stages, subpanels, metric lines, executive framing with Smart Brevity. Template template-portfolio.html, 920px container, h1 48px/700 in primary color, no badge. JS: theme toggle only.
Mode — CSS flowLinear A → B → C
Pure CSS Flowchart. Use when: linear flow (any length), no branching, perfect vertical alignment, zero JS dependencies. Flexbox column + arrow nodes with actor tags. 1100px container, centered hero. JS: theme toggle only.
03

Non-negotiable design constraints

These rules override visual-explainer defaults. Every page must comply.

Typography
& color
  • Fonts: Fraunces (headings/body) + Source Code Pro (mono)
  • Palette: Gulf Stream Racing — orange primary, blue secondary, teal metric
  • Dark mode: html.dark class toggle, not @media prefers-color-scheme; storage key diagram-theme
  • No emoji — Unicode entities only
Mermaid rules
  • Import mermaid@11/dist/mermaid.esm.min.mjs
  • Config startOnLoad: true, theme: 'base', look: 'classic'
  • Never layout: 'elk' — it blanks the diagram
  • classDef uses hardcoded rgba/hex, not CSS variables
  • A CSS bridge overrides fill/stroke per class for dark mode
Layout &
navigation
  • Nav: sticky, blur backdrop, brand link + theme toggle
  • Backlink: fixed top-left, parent-relative path
  • Favicon: ../icon.svg, adjusted for depth
  • Footer: copyright + LinkedIn link
  • Reduced motion: a @media (prefers-reduced-motion: reduce) block
Zoom &
interactivity
  • Zoom controls +/−/reset on every .mermaid-wrap
  • Ctrl+scroll zooms the diagram container
  • Click-drag pans when zoomed in
  • Cursor switches grab → grabbing while panning

Overrides to visual-explainer defaults

Colors: Gulf Stream Racing, not visual-explainer’s aesthetic picks. Theme: html.dark class toggle with localStorage. Nav: sticky blur-backdrop with brand + toggle. Backlink: fixed-position. Mermaid: never ELK, always look: 'classic'. Flowcharts: linear = pure CSS, branching = Mermaid. Fonts: always the repo pair.
