Stage 7 — Demo Test Plan

Stark Industries PMO · 6 scenarios · what to do · what should happen

TEST PLAN

3 scenarios, 3 signals. Each walks a distinct path through the system: approval with full pipeline, SLA breach with live notification, and rejection. 30 minutes total — 10 min process walkthrough, 15 min demo, 5 min Q&A buffer.

#ScenarioWhat you doWhat should happen
1 Arc Reactor Cooling System Upgrade
ITAPPROVE PATH
Tony Stark · $200k+ · complete data 		1. Open Intake Board
2. Point out AI Summary, Completeness Score, Status = Pending Review
3. Explain: "Formula + AI already processed this"
4. Assign PM
5. Change Status to Approved 		AI summary generated on creation
Completeness Score = Complete
Status auto-set to Pending Review (Automation 1)
On Status Approved: Automation 4 fires — creates Execution Board item, links via Connect Boards, notifies PM
Portfolio Board gets connected item
Talking point: "One status change triggers the entire downstream pipeline."
2 Supply Chain Disruption — Palladium Sourcing
OpsSLA BREACH
Pepper Potts · $200k+ · Eval Deadline: today · no decision 		1. Open the item
2. Point out Evaluation Deadline has passed
3. Check bell icon for Automation 3 notification
4. If not fired: set Eval Deadline to today, watch it fire
5. Show SLA Progress column 		Evaluation Deadline = past due
Automation 3 fires: "When date arrives and Status Approved/Rejected notify Assigned PM and Pepper"
Bell icon shows notification
Talking point: "This is the SLA breach automation. One notification when the clock expires. In Phase 2, I'd add a 2-day-out warning and a multi-stage escalation ladder."
3 Office Ping Pong Tournament
HRREJECT PATH
Clint Barton · Under $50k · morale project 		1. Open the item
2. "Is this actually a project?"
3. Change Status to Rejected
4. Verify no Execution item created
5. Check Portfolio stays clean 		Shows the Rejected path in the Status pipeline
Automation 4 does NOT fire (Status Approved)
No Execution Board item created
No clutter on Portfolio or Dashboard
Talking point: "Not everything that comes through intake is a project. The pipeline lets PMs say no — and 'no' is fast. In Phase 2, I'd auto-notify the requestor with the reason."
