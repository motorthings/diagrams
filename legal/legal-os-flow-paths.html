How Harvey Gets Evaluated
1. Register the Harvey agent — name, type, system prompt snapshot
2. Submit a Harvey output — user prompt + Harvey's response
3. Evaluate — 4 scorers run in parallel (Accuracy, Safety, Bias, Compliance)
4. Score — weighted formula with veto. Certification assigned.
5. Monitor — weekly drift checks compare output against baseline
6. Alert — if drift exceeds threshold, PM gets notified
Technology owns the agent. Legal-OS owns the measurement.
