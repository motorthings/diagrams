The Hardest Problem
Independent Harvey Agent Evaluation
Harvey can't grade its own homework. The same AI system that generates an output cannot reliably evaluate that output. This is the architectural problem every law firm with Harvey will eventually face — and Legal-OS solves it with an independent evaluation layer ported from the AESOP evaluation engine.

How Harvey Gets Evaluated
External agents deployed by Technology are pulled into Legal-OS for independent 4-dimension scoring. Technology owns the agent. Legal-OS owns the measurement.
Evaluation Pipeline
  • Register Harvey agent with baseline system prompt snapshot
  • Submit Harvey output (user prompt + response)
  • 4 evaluators run in parallel — Accuracy, Safety, Bias, Compliance
  • Weighted scoring: Tier 1 at 1.5×, Tier 2 at 1.0×
  • Hard veto: any Tier 1 dimension below 75 caps final at 74.9
  • Certification: Platinum 90+ → Gold 85+ → Silver 80+ → Bronze 75+
  • Weekly drift detection across 6 drift types
  • Auto-generated alerts at severity: moderate → high → critical
Why It Matters
  • 700+ hallucination cases in courts — those happened because nobody was checking
  • Vendor promises become auditable evidence — every output scored, every boundary verified
  • Drift detection catches quality degradation before it becomes a sanction event
  • Provider resilience: tries Anthropic first, auto-falls-back to DeepSeek on any auth error
  • Production evaluation: 90.5 average score, 5.3s for all 4 dimensions in parallel
  • Scoring engine ported directly from AESOP — same formula, same veto, same certification tiers
  • 21 dedicated tests validating every scoring path and veto condition

How It Works
  • User asks a question in the slide-out panel
  • Voyage AI generates a 512-dim embedding
  • pgvector similarity search across 89 indexed chunks
  • Top 5 chunks become context for the LLM
  • Answer returned with source references
  • Thumbs up/down feedback on every answer
  • Falls back to keyword-matched FAQ if API unreachable
