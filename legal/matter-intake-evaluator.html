Matter Intake Evaluator

Two-stage AI pipeline. Paste a matter summary. Get back classification, conflict check, risk assessment, and staffing recommendation — with scores and reasoning in legal terminology.

Pipeline — Pure CSS Flowchart

Programmatic Scoring
Weighted calculation across all 5 dimensions. Never trusts LLM scores directly — applies deterministic weights and rules. Conflict type gates score levels.
Deterministic

Five Evaluation Dimensions
25% — Classification
Practice Area Classification Accuracy
Is the matter correctly classified? Does it span multiple practice areas? Router confidence + evaluator re-confirmation. Cross-practice elements flagged.
25% — Risk
Urgency & Risk Assessment
Deadlines, regulatory exposure, financial stakes, reputational risk. Scored as inverted risk — lower risk = higher score. Urgency: immediate / short-term / routine.
20% — Conflicts
Conflict Check Completeness
Adverse parties identified. Business conflicts flagged. Prior representations checked. Direct adverse = highest score (conflict found). None identified = baseline.
15% — Staffing
Staffing Recommendation Quality
Role recommendation + hour estimate. Partner oversight assessed. Specialty requirements identified. Scored on completeness — has role + hours = higher score.
15% — Integrity
Client/Matter Data Integrity
What's missing from the intake? How clear is the summary? Completeness and clarity scored 0-100. Issues surfaced explicitly so intake can be improved.
Scoring Formula — Deterministic, Never Trusts the LLM
overall_score = (PA_classification × 0.25) + (urgency_risk × 0.25) + (conflict_check × 0.20) + (staffing × 0.15) + (data_integrity × 0.15)

Risk level thresholds: ≥70 = Low  ·  40-69 = Medium  ·  <40 = High

Technical Architecture
Backend
FastAPI + Pydantic
Single POST /api/evaluate endpoint. Two-stage async pipeline. Provider auto-detection from API key prefix. Structured JSONL logging.
LLM Provider
Auto-detect: Anthropic or OpenAI-compatible
sk-ant- prefix → Anthropic (Claude). sk- prefix → OpenAI-compatible (DeepSeek). Separate model + temperature per stage.
Frontend
Next.js 16 — Single Page
State machine: empty → loading → success / error. Textarea input, risk badge, 5 score cards with bars, conflict + staffing panels. No auth. No routing.
Design Choices
Stateless. No database. No auth.
Demo-scoped. Wide-open CORS. Programmatic scoring never trusts LLM-generated scores. Two-stage pipeline separates classification from evaluation.
