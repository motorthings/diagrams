System Page Data Flow

The System page is read-only. On mount, loadSystemInfo() fires three concurrent requests:

GET/api/health
Returns {"status":"ok","service":"glean-agent-factory"}
Sets green/red dot on Backend API status tilepage.tsx → lib/api.ts → health.py
GET/api/settings
Reads settings table, merges defaults from config.py.
Provides default_model and output_dir.page.tsx → lib/api.ts → app_settings.py → SQLite
Electron IPCwindow.electronAPI
getAppVersion() — Returns Electron app version string
platform — Returns process.platform (e.g., “darwin”)page.tsx → preload.js → main.js
