Gmail Automation · System Design

Email Triage & Response Pipeline

A rules-driven automation that polls Gmail on a regular cadence, classifies incoming emails through a multi-factor triage engine, and routes each message to one of five outcomes — from fully automated replies to human-review drafts. Gemini AI handles both intent classification and response generation.

◈ Gemini AI touchpoints. The model is invoked at two stages: (1) Intent classification — reading the email and returning a structured label (scheduling_request, urgent, invoice, etc.) plus a confidence score — and (2) Response generation — drafting the reply body for auto-reply and draft-response outcomes. A single API key from aistudio.google.com is all that's needed. Gemini 2.5 Flash free tier (~1,500 req/day) is more than enough for personal email volume.

Outcome Definitions

What happens to the email at each terminal

Auto-Reply

Gemini generates a response matching the thread's tone. Gmail API sends immediately via messages.send. Best for scheduling, simple Qs, and templated responses where confidence is high.

Draft Response

Gemini writes a reply, then drafts.create stores it in Gmail's Drafts folder. The user reviews and sends manually. Default for most non-trivial messages.

Flag for Review

Starred + labeled Needs Attention. No AI reply generated — the human must respond. Optionally triggers a push notification for urgent items.

Archive / Skip

Marked read and archived via messages.modify (remove INBOX label). For newsletters, notifications, and automated emails that need no action.

Forward / Escalate

Forwarded to the right colleague, or the user gets a notification that this needs reassignment. Rare — for misrouted email and cross-team handoffs.

Configuration Surface

What you'd set up to make this run

Credentials

  • Gemini API key — from aistudio.google.com
  • Gmail OAuth2 — credentials.json from Google Cloud Console
  • Scopes: gmail.readonly · gmail.compose · gmail.send · gmail.modify
  • Set OAuth consent screen to "In production" (avoids 7-day token expiry)

Rule Configuration

  • VIP list — email addresses or domains
  • Newsletter blocklist — sender patterns to auto-archive
  • Team domain — for internal routing rules
  • Keyword maps — urgency triggers, legal/financial terms
  • Gemini prompt — system prompt for classification + tone/style for responses

Runtime

  • Option A: Google Apps Script — zero infra, built-in GmailApp, 5-min triggers
  • Option B: Python script on Railway / Render / home server — more control, any schedule
  • Option C: GitHub Actions — free cron, but emails visible in logs
  • Recommend starting with Apps Script, graduating to Python if outgrown

Safety Guards

  • Dry-run mode — log decisions without executing
  • Confidence threshold — only auto-reply above 90% confidence
  • Rate limit — max N auto-sends per hour
  • Allowlist-only auto-reply — restrict auto-send to known senders
  • Audit trail — every decision logged with rationale
